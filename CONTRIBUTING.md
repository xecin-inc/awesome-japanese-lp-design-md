# Contributing

Thank you for your interest in the DESIGN.md pattern packs.

- **Requests and bug reports are welcome via [Issues](../../issues/new/choose).**
  Use "Pack request" for an industry × mood you would like to see, and "Bug report" for lint errors or a broken preview.
- **Pull requests are accepted only for documentation fixes** (for example, typos in `CONTRIBUTING.md`).
  The contents of `packs/` (DESIGN.md and previews), `catalog.json` and the `README` files are generated every month by
  designmark's internal pipeline, which runs quality and rights checks before anything is published here.
  Pull requests that change them will be closed — please open an Issue instead.
- Takedown requests for designmark.jp are handled on the website (https://designmark.jp/takedown/), not in Issues.
- By contributing, you agree that documentation changes are licensed under CC BY 4.0 and script changes under the MIT License.

- **要望と不具合の報告は [Issues](../../issues/new/choose) で受け付けます。** 欲しい業種 × 雰囲気は「型パックの要望」、

- designmark.jp の掲載の削除依頼は、Issue ではなくサイトのフォーム（https://designmark.jp/takedown/）からお送りください。
