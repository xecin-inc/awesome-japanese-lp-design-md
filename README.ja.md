# AI コーディング向け 日本の LP デザイン設計書（DESIGN.md）の型パック

AI コーディングツール向けの、日本の LP（ランディングページ）のデザイン設計書（DESIGN.md）。公開されている LP の解析 1,396 件から合成しました。

[English](README.md) · [designmark.jp](https://designmark.jp/?utm_source=github&utm_medium=readme&utm_campaign=packs) · 型パック: CC BY 4.0 · スクリプト: MIT

**型パック**は、業種 × 主な雰囲気ごとに 1 つの `DESIGN.md` です。配色のトークン・書体・余白・角丸・部品・セクションの並び・守ること／避けることを、Claude Code・Cursor・v0 などの AI コーディングツールがそのまま読める形にまとめています。同じトンマナの LP を作るときの起点に使えます。

## 使い方

```bash
npx designmark add pk-cosmetics-cute    # 型パックの DESIGN.md をプロジェクトに保存する
```

- または `packs/<ID>/DESIGN.md` をプロジェクト直下にコピーし、`CLAUDE.md` に `@DESIGN.md` と 1 行書く。
- Claude Code のプラグイン: `/plugin marketplace add xecin-inc/designmark` → `/plugin install designmark@designmark`（[取得ツール](https://github.com/xecin-inc/designmark)）

## もっと探す

[designmark.jp](https://designmark.jp/?utm_source=github&utm_medium=readme&utm_campaign=packs) では、日本の LP 1 件ごとの DESIGN.md を 4,148 件公開しています（業種・雰囲気・色で探せます）。型パックは[型パックのページ](https://designmark.jp/packs/?utm_source=github&utm_medium=readme&utm_campaign=packs)にもあります。

## 型パックとは

- designmark（運営: 株式会社 XECIN）は、公開されている日本の LP の見た目を解析し、LP ごとの DESIGN.md を公開しています。
- 型パックは、そのうち業種と主な雰囲気が同じ設計書 20〜60 件（公開日の新しい順）を集計し、その値だけから 1 つの DESIGN.md を合成したものです。集計は、役割ごとの色のまとまり（CIEDE2000。代表色はまとまりの平均の色で、どれか 1 件の色をそのまま使わない）、書体のサイズの分布、余白と角丸の中央値、よく使われる部品、典型的なセクションの並びです。画像・元の LP の URL・文言は使っていません。
- **型パックは、特定の LP のデザインではありません。** 合成元のどれか 1 件に似すぎたもの（有彩色の配色・セクションの並びが同じ・文の写し）は不合格にしています。ロゴ・商品名・コピーも含みません。
- 月 1 回見直します。引退した型パックも `packs/` には残しますが、この一覧と `catalog.json` からは外します。
- `catalog.json` は、今の型パックの一覧です（[公開 API](https://designmark.jp/api/v1/packs/index.json) と同じ形）。
